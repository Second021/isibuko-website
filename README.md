# Isibuko SakwaZulu Website

### 🔗 Live Demo: [https://second021.github.io/isibuko-website/](https://second021.github.io/isibuko-website/)

---

## About

Official website for **Isibuko SakwaZulu**, the NWU Vaal Campus cultural society. We keep isiZulu language, music, dance and heritage alive on campus.

*Imvelaphi yethu yisibani sethu.*

## Sections

- **Home**: introduction to the society
- **Our Story**: who we are and what we stand for
- **Events**: what's happening on campus
- **Committee**: meet the team
- **Gallery**: photos from our events
- **Contact**: get in touch, join us, or follow us on TikTok and WhatsApp

## Built With

- HTML and CSS (single-page site)
- [Montserrat](https://fonts.google.com/specimen/Montserrat) font from Google Fonts
- Hosted free on GitHub Pages

## Run It Locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

## Update the Site

Edit `index.html` in this repository and commit the change. GitHub Pages republishes the site within a couple of minutes.
